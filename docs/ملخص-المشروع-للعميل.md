# بن مفيد (BenMufeed)  
## ملخص المشروع — عرض للعميل

---

### نظرة عامة

**بن مفيد** نظام متكامل لإدارة كافيتيريا / مطعم: موقع إلكتروني للزبائن، نقطة بيع للكاشير، شاشة مطبخ، إدارة مخزون وفواتير، وطباعة مباشرة على الطابعات — في منصة واحدة باللغة العربية.

---

### لمن هذا النظام؟

- كافيتيريات، مطاعم، وأماكن تقدّم مشروبات وأراكيل ومأكولات  
- فريق عمل يحتاج: طلبات من الموقع، طلبات الطاولات (QR)، كاشير، مطبخ، ومتابعة مالية يومية  

---

## 1. الموقع الإلكتروني (واجهة الزبون)

| الميزة | الوصف |
|--------|--------|
| الصفحة الرئيسية | عرض المنشأة، الأقسام، المنتجات، وسلايدر ترويجي |
| القائمة والأقسام | تصفّح المنتجات حسب التصنيف مع بحث |
| تفاصيل المنتج | أنواع (مثلاً: فواكه / موز / شوكلا) وإضافات (مكسرات…) مع أسعار واضحة |
| السلة والطلب | طلب **سفري** أو **توصيل** (مع خريطة لتحديد الموقع) أو **طاولة** عبر QR |
| طاولات QR | كل طاولة لها رابط/رمز؛ الزبون يطلب من جواله ويُضاف للطاولة المفتوحة |
| جلسة الطاولة | نفس الزبون يكمّل طلبه؛ حماية من تداخل زبائن آخرين حتى إغلاق الطاولة |
| واتساب | ربط رقم المنشأة للحجز والتواصل |
| SEO | خريطة موقع، robots، وصفحات من نحن / اتصل بنا / ساعات العمل |

**الرابط:** الصفحة الرئيسية للموقع (`/`)

---

## 2. نقطة البيع (POS) — الكاشير

| الميزة | الوصف |
|--------|--------|
| شاشة كاشير | بيع سفري، إرسال لطاولة، تعديل طاولة مفتوحة، إغلاق وتحصيل |
| الطاولات | عرض الطاولات المفتوحة والمغلقة وإدارة الإغلاق من شاشة مخصصة |
| تخصيص المنتج | اختيار النوع والإضافات قبل الإضافة للسلة (مثل الموقع) |
| تنبيهات | صوت وتنبيه عند طلبات جديدة من الموقع أو الطاولات |
| سجل الفواتير | عرض وتعديل وحذف فواتير POS مع **طباعة فاتورة مباشرة** |
| سجل الطباعة | تتبّع كل عملية طباعة؛ إعادة تشغيل ما فشل بضغطة واحدة |

**الرابط:** `/pos`

---

## 3. شاشة المطبخ (KDS)

| الميزة | الوصف |
|--------|--------|
| عرض الطلبات | تذاكر جديدة و«طبقات إضافة» لنفس الطاولة |
| حالة التحضير | تمييز الطلب كـ «جاهز» |
| طباعة تلقائية | إرسال تذكرة المطبخ للطابعة عند وصول الطلب (بدون نافذة متصفح) |
| طباعة يدوية | زر طباعة لأي تذكرة |

**الرابط:** `/kitchen`

## 4. الطباعة الاحترافية

| الميزة | الوصف |
|--------|--------|
| اختيار الطابعات | من الأجهزة المتصلة بالجهاز (عبر QZ Tray) |
| طابعة مطبخ + طابعة كاشير | إعداد منفصل لكل موقع عمل |
| طباعة صامتة | عند الطلب أو إغلاق الطاولة — **بدون** نافذة طباعة المتصفح |
| تصميم الفاتورة | عرض الورق (58/80 مم)، شعار، نصوص أعلى/أسفل الفاتورة |
| سجل الطباعة | نجاح / فشل / سبب الخطأ / إعادة المحاولة |

**إعدادات الطباعة:** `/admin/pos-printing`  
**سجل الطباعة:** `/pos/print-log`

**مجموعة «المطعم»:** نقطة البيع، شاشة المطبخ، الطباعة والمطبخ، سجل الطباعة

| الطبقة | التقنية |
|--------|---------|

## 9. ما يميز النظام عن حلول منفصلة

1. **قناة واحدة للطلب:** موقع + طاولة QR + كاشير → نفس قاعدة المنتجات والأسعار.  
2. **مطبخ متزامن:** كل طلب يصل كتذكرة مع تمييز الإضافات على طاولة مفتوحة.  
3. **طباعة حقيقية للمطاعم:** طابعات حرارية مباشرة، مع سجل فشل وإعادة.  
4. **مرونة المنتجات:** أنواع وإضافات بأسعار مختلفة (مثال: وافل، مشروبات).  
5. **عربي بالكامل:** واجهات RTL مناسبة للسوق المحلي.  
6. **مالية ومخزون:** ليس فقط POS — فواتير شراء، يومية، رواتب، وأرباح في نفس المنصة.

## 10. متطلبات التشغيل (للعميل / الفريق التقني)

- استضافة ويب تدعم PHP 8.2+ وقاعدة بيانات  
- على أجهزة الكاشير والمطبخ: تثبيت **QZ Tray** وربط الطابعات مرة واحدة  
- متصفح حديث على tablets/أجهزة POS  
- (اختياري) نطاق وشهادة SSL للموقع العام
